# Shadynasty 2.1 league site — design

Date: 2026-11-16

## Intent

Bring back what the old NCAA Football Online Dynasty website did: a place outside the game where the league can check where the dynasty stands, look at stats, and follow recruiting. The league is Shadynasty 2.1 on Xbox (EA Sports College Football 27), with two user coaches: Danny Bateman (Clemson) and Hogg McDoggnald Jr. (Texas). The owner is the commissioner.

## Goals

- One link both coaches can open on a phone or computer, with no login.
- It updates itself after each advance, with nobody pressing anything.
- It shows current status, stats for the two user teams, recruiting, and league history.
- History keeps building season after season.

## Non-goals

- Recruiting or any other action that changes the game. The game accepts nothing from outside.
- An ESPN-style front page with written stories (the owner called this very unimportant).
- Stats for CPU teams' players. The data source does not capture them.
- Per-coach recruiting boards or commitments per prospect. The data source does not expose them.

## Anti-goals

- The access token appearing anywhere in the published site or the repository.
- History disappearing if the data subscription lapses or the source drops old data.
- A site that needs the owner's PC switched on to stay current.

## Constraints

- Data comes only from Dynasty Rewired's read-only API (`https://dynastyrewired.com/api/developer/v1`, league `cfb27-738435`). Docs: `https://dynastyrewired.com/developer/llms.txt`, field glossary at `/developer/data`.
- The API cannot be called from a browser, so data is fetched by a script and baked into the pages.
- Limits: 60 requests a minute and 2,000 a day. Data only changes when a new capture is saved.
- The league is on a free trial (8 advances or 2 weeks). After that the API returns 402 until the owner subscribes at $3.99 a month.
- Verified on 2026-11-16 against live data:
  - Schedule: 138 teams, 893 games, records and conference records. Present for 2037 only; 2026–2036 return empty.
  - Box scores: 4 games, apparently user games only. Team stats and per-player stats keyed by EA stat codes.
  - Rankings: media, coaches and playoff polls by week.
  - Recruiting: class rankings for 138 teams; a pool of 4,100 prospects with rank, stars, position, archetype, hometown, state. No commitment or interest fields seen.
  - Postseason: champions for 2026–2036 with coach and score.
  - Awards: 2036 winners available; 2037 pending.
  - Coaches: both user head coaches with career, bowl and playoff records.
  - Rosters: every school, with ratings.

## Approaches considered

1. **Use Dynasty Rewired's own site, build nothing.** Works immediately, but shows what they chose to show. No head-to-head view, no control over the record book.
2. **Custom site on their API (chosen).** Same cost, since the API is included. More work, but the league shapes it. The owner picked this.
3. **Screenshots through Xbox's OneDrive upload.** Free, but every coach would have to capture screens each week. Dropped once it was clear the site is for the whole league.
4. **Reading the save file.** PC only. Dropped: the league is on Xbox.

## How it works (builder's calls unless marked)

- **Static site, generated by a script.** A Node script (no framework, Node 24 is installed locally) fetches the data, saves it as JSON, and writes plain HTML pages with one shared stylesheet. Reason: nothing to run or pay for, and it loads fast on a phone.
- **Hosting on GitHub Pages, updated by a scheduled GitHub Actions job** (owner agreed to GitHub hosting in principle; needs their account). The job runs hourly, asks the API for the league's current stage, and only fetches everything and rebuilds when the stage or a capture time has changed. The token lives in a GitHub Actions secret and in a local `.env` that is git-ignored.
- **Fetched data is committed to the repository** under `data/<season>/`. This is the archive: record books and past seasons are built from these files, not from asking the API again. If the API returns 402 or an error, the job leaves the last good site in place and fails visibly.
- **Request budget:** one league call per hourly check; a full refresh is about 10 calls plus box-score pages plus two roster calls (user teams only). Far inside the limits.
- **Stat codes** are translated to readable names with a lookup table taken from the data reference.

## Pages

- **Home:** current week; for each user team its record, rank, last result and next game; the top 25.
- **Team page (Clemson, Texas):** schedule and results, roster with ratings, season stat leaders (passing, rushing, receiving, defense, kicking) summed from box scores.
- **Head-to-head** (builder's proposal, owner approved): the two coaches side by side with career record, bowl and playoff records, national titles, and results of games between them. Meetings can only be listed from 2037 on.
- **Recruiting:** class rankings with the two user teams highlighted; the prospect pool, filterable by position, stars and state. The filter runs in the browser over a JSON file.
- **History:** champions by year, award winners by season, and a record book (single-game and season bests for user-team players) that starts in 2037.

## Left to the builder

- Visual styling, beyond being readable on a phone and in dark or light mode.
- Exact stat categories and how many leaders to list.
- File layout and how pages are templated.
- Whether a manual "refresh now" trigger is added alongside the hourly job.

## Open items for the owner

- A GitHub account to host under, and whether the site may be publicly reachable (free GitHub Pages sites are public; the league is already public on Dynasty Rewired).
